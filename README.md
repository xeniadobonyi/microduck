# Microduck homepage

Static concept homepage for the Microduck robot duck, with desktop and mobile layouts.

## Run it locally

No install needed. From this folder:

```
python3 -m http.server 8000
```

Then open http://localhost:8000. (Opening `index.html` directly also works, but some browsers block autoplaying video from `file://`.)

## Work on it with Claude Code

```
cd microduck-site
claude
```

`CLAUDE.md` describes the structure, design system and open items, so Claude Code picks up the context automatically.
